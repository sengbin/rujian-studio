# 如见 Studio 用户使用手册

从创意、图片或小说开始，逐步制作剧本、分镜、资产并生成短视频。本手册按应用当前向用户开放的页面和操作介绍完整工作流程。模型及平台能力可能更新，实际可选项以应用界面为准。

## Skill 使用规则

- 用户询问具体操作时，给出界面入口、逐步操作、字段填写要点、成功后的状态和阻止条件；涉及删除、覆盖、重新生成或恢复时，说明影响及确认要求。
- 用户要求完整流程时，依据下方全部章节说明，不要只给快速开始；标出制作阶段的前置条件、确认关系和返回修改方式。
- 用户是第一次使用、询问如何获取访问密钥（API Key）或如何配置模型时，依据“从零开始：获取访问密钥并配置模型”逐步回答，并先确认他要用的服务商和内容类型；不索要密钥本身。
- 使用应用实际显示的中文界面标签。模型清单和平台能力可能变化时，以当前“设置 › 模型”页面和平台提示为准；不声称手册未记载的按钮、快捷键或能力。
- 用户询问尚未集成的服务商、模型类型或应用未开放的参数时，明确说明当前支持范围，不把平台本身具备的能力说成应用已支持。
- 说明费用、取消任务后平台端可能继续运行，以及恢复备份会替换当前数据等重要影响；故障排查依据界面错误分类、平台原文和处理建议，不臆测服务端状态。
- 用户的问题超出本手册时，不把“常见问题”列表当成唯一支持范围；按下方答疑流程结合用户提供的界面状态和错误信息排查。

## 用户答疑流程

1. **先分类问题**：安装/打开、模型或密钥、项目/作品、创意/剧本/分镜、资产/提示词/版本、绑定/视频生成、结果导出、备份恢复。
2. **确认必要上下文**：询问用户所在页面和执行的动作、所选模型/服务商、界面显示的状态或完整错误文字、出错前的操作步骤；只询问解决问题所必需的信息。
3. **按手册逐项定位**：先核对前置条件、当前状态、模型能力、字段限制和阻断项；区分应用本地校验、服务商接口、账号/额度及网络问题，不把推测说成结论。
4. **给出可执行的下一步**：按“检查位置 → 应看到什么 → 不符合时如何修正 → 修正后怎么重试”回答，并注明取消、覆盖、重新生成或恢复可能造成的影响。
5. **信息不足或问题未覆盖时**：说明目前能确认和不能确认的部分，提出最少的补充问题；必要时请用户提供脱敏后的错误文字、状态和步骤。未知平台行为以服务商当前页面/通知为准，不编造错误码含义或承诺一定解决。

不要索要或复述访问密钥、令牌、账户密码、私有小说/素材原文或其他敏感内容。若用户贴出密钥，提醒其撤销并重新生成密钥；排查只需核对“已配置/未配置”、服务商、模型名和脱敏后的错误。

## 功能概览

- **项目与作品**：用项目组织作品；作品支持单个短视频或多集短片（电视剧、电影即将推出）。
- **创作起点**：文字灵感、最多 10 张图片、TXT / Markdown 小说（长篇小说可以自动分段处理），或原创文稿（自己的文章，文字原样保留、不被改写）。
- **创意、剧本、分镜**：分阶段生成并由用户确认；上游内容变化时，下游会提示“上游已变更”。
- **资产库与实体绑定**：管理角色、场景、道具、特效和音频资产，并把剧本实体关联到资产。
- **视频工作台**：按镜头组生成视频、管理队列、重试失败任务、播放和采用结果版本、导出视频。
- **数据备份**：备份项目数据，以及资产、镜头首帧、尾帧的图片与音频和上传的灵感图片、小说、原创文稿等本地文件；视频结果文件和访问密钥不包含在备份中。

## 使用前准备

1. 使用 Windows 系统并安装如见 Studio（见下文“安装与打开”）。
2. 准备文本生成模型：在“设置 › 模型”启用千问AI平台、火山引擎或 MiniMax 的文本模型并配置访问密钥。多个文本模型可以同时启用。各平台怎么获取访问密钥、怎么在应用里配置，见下文“从零开始：获取访问密钥并配置模型”。
3. 生成图片和视频需要千问AI平台、火山引擎或 MiniMax 的访问密钥（可以只配其中一家）；生成音频需要千问AI平台、豆包语音或 MiniMax 的访问密钥。火山引擎与豆包语音是两个独立服务商，访问密钥分别在火山方舟控制台和豆包语音控制台创建，不能通用。
4. 图片灵感支持 PNG、JPEG、WebP，每张不超过 10 MB；小说改编和原创文稿支持 UTF-8 编码的 TXT / Markdown 文件，不超过 5 MB（原创文稿也可以直接粘贴文字）。

## 安装与打开

- 运行安装包 `RUJIAN Studio-x.y.z Setup.exe` 完成安装；应用目前只提供 Windows 版本。
- 安装后从开始菜单或桌面快捷方式打开 **如见 Studio**。

应用以左侧菜单作为入口，页面在右侧以标签形式打开。

升级时运行新版本的安装包。迁移电脑、重装或卸载前，先在“设置 › 数据备份”创建备份；备份不包含视频结果或访问密钥，需保留的视频文件应另行复制。

## 从零开始：获取访问密钥并配置模型

第一次使用时先完成本节，之后所有生成功能才有可用的模型。访问密钥由各模型平台签发，应用不提供，也不代收费；调用产生的费用由平台向你的账号收取。平台的控制台页面和入口名称可能调整，以平台当前页面为准。

### 第 1 步：选择服务商

先决定要生成哪几类内容，再选能覆盖它们的服务商。四类内容至少各要有一个已启用的模型：

| 内容 | 可选服务商 |
| --- | --- |
| 文本（创意、剧本、分镜脚本、资产提示词） | 千问AI平台、火山引擎、MiniMax |
| 图片（资产图） | 千问AI平台、火山引擎、MiniMax |
| 音频（声音资产、台词配音） | 千问AI平台、豆包语音、MiniMax |
| 视频 | 千问AI平台、火山引擎、MiniMax |

只想少配一份密钥时，选千问AI平台或 MiniMax 即可覆盖四类。选火山引擎时，音频需要另外配置豆包语音，两个服务商各有一份访问密钥，互不通用。

### 第 2 步：在平台获取访问密钥

各平台的共同流程：注册并登录平台账号 → 确认账号有可用余额或免费额度（部分平台还需实名认证）→ 创建访问密钥 → 立即复制并妥善保存（多数平台只在创建时显示一次完整密钥）。不要把密钥发给别人，也不要贴到聊天或截图里。

**千问AI平台**

1. 注册并登录千问AI平台（`platform.qianwenai.com`）。
2. 打开控制台的“API Key”页面（`platform.qianwenai.com/home/api-keys`），点“创建 API Key”。
3. 输入便于辨认的描述，点“生成 API Key”。
4. 立即复制密钥；完整密钥只在创建时显示一次，之后列表只显示掩码。
5. 使用通用 API Key（按调用量计费，格式为 `sk-ws-` 开头，早期创建的为 `sk-` 开头）。Token Plan 订阅专属的 Key（`sk-sp-` 开头）绑定订阅套餐、按 Credits 计费，不是本手册所述的通用 Key。
6. 在平台的计费页面确认账户有余额或新用户免费额度，余额不足时先充值。

**火山引擎（方舟）**

1. 注册火山引擎账号并完成实名认证，登录火山方舟控制台。
2. 在控制台左下角打开“API Key 管理”（`ark.volcengine.com/region:cn-beijing/apiKey`），点“创建 API Key”并复制。
3. 打开“开通管理”页面（`ark.volcengine.com/region:cn-beijing/openManagement`），开通要使用的模型服务。没有开通的模型调用时会报鉴权或未开通类错误。
4. 确认账号有可用余额或免费额度。

**豆包语音**（只用于音频，与火山方舟是两个独立服务）

1. 使用同一个已实名认证的火山引擎账号登录豆包语音控制台（新版控制台 `console.volcengine.com/speech/new`）。
2. 新用户首次开通时，可点“服务开通”快捷入口，一键开通默认项目（`default`）下的全部模型并领取免费试用礼包（仅首次赠送）；非默认项目需要在“开通管理”里自行开通要用的服务。
3. 在概览页“畅快使用”处点“API接入”即可看到并复制 API Key（系统默认会创建一个）；也可以在左侧导航的“API Key 管理”里点“创建 API Key”。
4. 控制台资源按项目隔离，API Key 与已开通的服务要在同一个项目下。免费额度用完后按后付费计费。
5. 豆包语音的 API Key 与火山方舟的不通用。

**MiniMax**

1. 注册并登录 MiniMax 开放平台（`platform.minimax.cn`）。
2. 打开“账户管理 › 接口密钥”，点“创建新的 API Key”并复制。按量付费的 API Key 可调用文本、图像、语音、视频全部类型的模型；要使用全部类型，请用这类密钥。
3. 按量付费需要在“账户管理 › 余额”充值。
4. 如果你购买了 M Plan 订阅，订阅 Key 在“订阅管理 › M Plan”查看。订阅 Key 与按量 Key 相互独立，M3.1 Flash 预览模型只有订阅 Key 能调用。
5. 企业团队建议用主账号创建子账号分配使用；子账号与主账号共享消耗、统一结算。

### 第 3 步：在应用里配置

1. 点左侧菜单“设置 › 模型”。页面上方是“文本生成”设置，下方“模型服务商”列表每个服务商一行，显示“已启用/已停用”和“密钥已配置/密钥未配置”。
2. 点目标服务商那一行的“设置”，打开服务商设置页。
3. 打开右上角的“启用”开关。
4. 在“访问密钥”输入框粘贴第 2 步复制的密钥，点“保存密钥”。密钥不能含空格或换行；保存成功后输入框清空，状态变为“已配置”，页面不会再显示密钥。
5. 点“测试连接”。每个接口地址各测一次，成功会在该地址名称右侧显示“连接成功！”；失败会显示分类和平台原文，按下方“常见卡点”处理。豆包语音的测试会用“你好”真实合成一次，产生极少量费用；千问AI平台、火山引擎和 MiniMax 的测试不产生生成费用。
6. “接口地址”等设置项一般保持默认值。留空保存会恢复默认值；修改时确认每个地址对应的模型类型正确，软件不校验网址格式。
7. 在设置页下方的“模型”区，按文本、图像、音频、视频标签切换，把要使用的模型的“启用”开关打开。所有模型默认都不启用；每个要用的类型至少启用一个。价格列仅供参考，以官网为准。
8. 关闭设置页回到列表，确认该行显示“已启用”“密钥已配置”和已启用的模型数量。要用多家服务商时，重复第 2 至 8 步。
9. 回到“文本生成”，在“默认文本模型”下拉里选一个已启用的文本模型；不选时，系统使用第一个已启用的服务商文本模型。

### 第 4 步：确认配置可用

- 打开任意生成表单（如新建创意、新建资产），“文本模型”“视频模型”等下拉里应出现刚启用的模型；资产的“生成图片”“生成音频”按钮不再置灰。
- 想实际验证，可以创建项目后用一小段文字灵感点“创建并生成”（会产生少量文本模型费用）。
- 之后按“快速开始”继续。

### 常见卡点

| 现象 | 处理 |
| --- | --- |
| “保存密钥”提示不能为空，或不能包含空格或换行 | 重新复制完整密钥，粘贴后检查首尾没有多余内容 |
| “测试连接”提示密钥或账号问题（鉴权） | 确认密钥属于该服务商且未被删除；火山方舟与豆包语音的密钥不通用；账号欠费、未开通模型服务也会报此类错误 |
| 提示接口地址不对或找不到 | 软件不校验网址格式；确认地址对应的模型类型正确、服务商可访问，再恢复默认地址重试 |
| 配置完成但生成表单里没有模型 | 同时检查三项：服务商已启用、密钥已配置、所需模型已启用；还要看该类型是否有已启用的模型 |
| 视频模型能选，提交后提示未开通 | 火山方舟需要在“开通管理”开通对应模型；豆包语音需要在控制台开通语音合成服务 |
| MiniMax 的 M3.1 Flash 预览模型调用失败 | 该模型只有 M Plan 订阅 Key 能调用，按量付费的 API Key 不行 |
| 想看账户余额和用量 | 在服务商列表点该行的“查询余额”“查询用量”；火山引擎还需要另外设置账户密钥，见“查看模型价格、账户余额与用量” |

## 快速开始

1. 先按上一节“从零开始”获取访问密钥；打开“设置 › 模型”，启用千问AI平台、火山引擎、豆包语音或 MiniMax，填写访问密钥、测试连接，并启用要用的模型。
2. 在“项目 › 所有项目”中创建项目。
3. 在“创作 › 文字灵感”旁点“添加”，输入灵感并选择“创建并生成”。
4. 检查生成的创意，编辑后点“确认采用”。
5. 在“脚本 › 剧本”添加剧本，生成并确认。
6. 在“脚本 › 分镜”添加分镜，选择视频模型、画幅等选项，生成并确认。
7. 在资产库准备角色、场景等素材，并在工作台绑定实体。
8. 打开“视频 › 生成工作台”，检查参数并提交镜头组，完成后采用需要的结果。

| 分区 | 功能 |
| --- | --- |
| 项目 | 所有项目，可创建项目 |
| 创作 | 文字灵感、图片灵感、小说改编、原创文稿 |
| 脚本 | 剧本、分镜 |
| 资产 | 角色、场景、道具、特效、音频 |
| 视频 | 生成工作台 |
| 设置 | 模型、数据备份 |

通常，点击功能名称打开列表，点击右侧“创建”或“添加”按钮新建内容。

### 列表页通用操作

- 列表异步加载时会显示“加载中…”。加载失败时先查看页面错误信息，再点“重试”；操作失败时按页面提示修正输入或设置。
- 项目列表可按项目名称搜索。创作和脚本列表可按作品名称搜索、按项目筛选；资产列表可按分类筛选并搜索资产名称。
- 列表的“操作”列只显示该对象当前允许的操作。生成中的阶段不能编辑；历史阶段版本为只读，切换到最新版本后才可编辑。
- 页面在作品、资产或生成状态发生变化后会刷新；若页面仍显示旧状态，可重新打开相应页面确认最新状态。

## 配置模型

进入“设置 › 模型”：

- **文本生成**：“默认文本模型”用于未单独指定模型的作品和资产提示词。创意、剧本、分镜和资产提示词生成表单也可选择本次使用的文本模型。
- **千问AI平台**：打开平台设置、启用服务商并填写访问密钥后保存。密钥经系统加密后保存在本机，不写入作品数据库或备份文件。默认接口地址（图片、视频、音频共用）为 `https://maas.qianwenaiapi.com/api/v1`，文本使用单独的“文本接口地址”，默认 `https://maas.qianwenaiapi.com/compatible-mode/v1`；修改时地址格式不限。点“测试连接”会分别检查两个地址与密钥，结果显示在各自地址名称右侧。
- **火山引擎**：设置方式与千问AI平台相同。“接口地址（图片、视频）”默认 `https://ark.cn-beijing.volces.com/api/v3`，“文本接口地址”默认也是这个地址，使用 Coding Plan 套餐时把文本地址改成套餐专用地址（如 `https://ark.cn-beijing.volces.com/api/coding/v3`）；两个地址共用同一份访问密钥（在火山方舟控制台创建），地址格式不限（可填代理或其他套餐的地址）。“测试连接”会分别检查两个地址与密钥，结果显示在各自地址名称右侧。
- **豆包语音**：火山引擎的语音合成产品，是独立的服务商，有自己的访问密钥（豆包语音控制台的 API Key，与火山方舟的密钥不通用）。“接口地址”默认 `https://openspeech.bytedance.com/api/v3/tts/unidirectional`，地址格式不限。“测试连接”会用“你好”两个字真实合成一次，产生极少量计费。
- **MiniMax**：一个服务商同时提供文本、图像、语音和视频，共用一份访问密钥（开放平台“接口密钥”中创建；M Plan 订阅 Key 与按量付费的 API Key 相互独立，M3.1 Flash 预览模型只有 M Plan 订阅 Key 能调用）。“接口地址”默认 `https://api.minimax.cn`，文本、图像、语音、视频共用这一个地址，地址格式不限。“测试连接”只查询一个不存在的视频任务，不产生费用。
- **模型启停**：服务商设置里的模型按文本、图像、音频、视频分成标签，有几种类型就显示几个标签，点标签（或按左右方向键）切换，标签后显示“已启用数/总数”，重新打开时沿用上次选的标签；每个标签下列出该类型的模型及其支持能力。只有服务商已启用、密钥已配置且模型已启用时，相关模型才可在其他页面选择。所有模型默认都不启用，需要逐个启用。在这里启用、关闭模型或更换默认文本模型后，已经打开的表单和对话框里的文本、图像、声音、视频模型下拉会立即更新，不用关闭重开；已填写的内容和仍可用的所选模型保持不变，所选模型被关闭时会自动改选当前可用的模型。
- **小说分段设置**：可设置按章节或按字数分段，以及每段字数上限。按章节识别不到章节标题时会改用按字数；单章超过上限时会继续在段落处切分。
- **模型不可用**：系统会优先使用作品单独选择的模型、默认文本模型，再使用第一个已启用的服务商文本模型。

### 设置服务商、密钥与单个模型

1. 在服务商列表中找到目标服务商，查看其启用状态、密钥状态、模型类型及已启用模型数量。
2. 点该服务商“设置”。服务商详情中的“启用”开关控制此服务商是否可用。
3. 在“访问密钥”输入框粘贴密钥，点“保存密钥”；已保存的密钥不会回显。需要换密钥时输入新值并保存；点“清除密钥”并确认后会删除已保存密钥，相关模型将无法调用。
4. 点“测试连接”检查当前保存的密钥和服务商设置，每个接口地址各测一次。测试结果显示在对应地址名称的右侧；没有密钥等无法测试的原因显示在密钥区域；未配置密钥时按钮不可用。
5. 修改服务商设置项时，下拉选项变更后立即保存；文本设置在输入框失焦后保存。每个字段会反馈“保存中…”“已保存”或失败原因。
6. 在模型表中按实际需要开关各个模型。变更立即保存；关闭某个模型后，它会从相应的模型选择列表中移除。
7. 关闭服务商设置页后，服务商列表会重新读取状态。

## 项目与作品

### 项目

在“项目 › 所有项目”中，可以按项目名称搜索。列表显示项目名称和描述、视觉风格、作品数量及更新时间；在某一行的“操作”列可点编辑或删除。

新建或编辑项目时填写：

- **项目名称**：必填且唯一，最多 50 字。
- **项目描述**：可选，最多 500 字。
- **视觉风格**：可从预置风格选择，也可选“其他”手动填写，最多 50 字。新创作、角色、场景及分镜可沿用；修改后不会回改既有内容。
- **默认画幅、默认分辨率**：可留空；作品或镜头可覆盖。视频模型不支持的选项不会出现在可用选择中。

点“保存”提交。名称重复或必填项无效时，按字段提示修改。

删除项目时，确认框会列出受影响的作品数和视频结果数；必须输入完整项目名称确认。项目、其中作品和生成结果记录会一并删除且无法恢复，资产库不属于项目，不会随之删除。

### 创建作品与生成创意

在“创作”下点对应类型旁的“添加”。若没有项目，应先创建项目。新建作品必须选择所属项目（创建后不能转移）、唯一作品名称（项目内唯一，最多 60 字）和作品形态：

- **单个短视频**：只有一集。
- **多集短片**：剧本确认后可拆分为多集；剧本确认后不能再修改作品形态。
- 电视剧、电影显示为“即将推出”，暂时不能选择。

再按所选入口提供素材：

| 起点 | 输入 |
| --- | --- |
| 文字灵感 | 输入创作主题或灵感 |
| 图片灵感 | 选择 1 至 10 张图片，并可调整图片顺序 |
| 小说改编 | 选择小说文件；可填写“必须保留”和“允许调整”的内容 |
| 原创文稿 | 选择 TXT / Markdown 文件，或直接粘贴文字（二选一，最多 1,000,000 字），没有题材、基调、字数和补充要求等生成参数 |

图片至少 1 张、最多 10 张；支持 PNG、JPEG、WebP，每张不超过 10 MB。点击缩略图可看原图，并可调整素材次序。小说文件须为 UTF-8 编码的 TXT / Markdown，大小不超过 5 MB。

新建表单其余字段：

- **文本模型**：选择用于创意生成的文本模型；后续生成剧本和分镜时也可再选。
- **创作主题或灵感**：仅文字灵感作品显示，可选，最多 2,000 字；留空则根据题材、基调和补充要求创作。
- **题材、基调**：可从预置值选择，也可选择“其他”填写自定义值。
- **每章大约最少字数、每章大约最多字数**：均为必填，范围为 100 至 100,000 字；最多值至少比最少值多 50 字。字数是生成目标而非严格保证，超出范围时页面会提示。
- **章节数上限**：必填，1 至 100；内容不足时不会为了达到上限而扩写。
- **图片中必须保留的元素 / 必须保留的内容**：非文字素材作品可填写，最多 1,000 字。
- **允许调整的内容**：小说改编可选，最多 1,000 字；留空表示尽量忠实原作。
- **补充要求**：可选，最多 2,000 字。

新建表单底部除“创建并生成”外，还有一个“参考节拍表生成”按钮；新建时作品还不存在，不可能有已确认节拍表，这个按钮始终禁用，按钮上方有说明文字。点“创建并生成”后会打开创意产出页。后台生成中可看当前阶段进度；生成未结束时可点“取消生成”。失败时先看失败原因，可点“重试”；不满意时点“重新生成”打开同一张表单。重新生成表单底部有两个按钮：“开始生成”仍是自由创作，不限字数、优先保证内容完整；“参考节拍表生成”按已确认节拍表的节拍数生成章节并向参考字数靠拢（此时上面的字数范围和章节数上限不生效），点击后会替换当前内容，按钮上方有说明；作品没有已确认的节拍表时这个按钮禁用。重试时若素材或小说分段设置已变，会提示旧进度和章节将被丢弃并从头开始。

生成后的章节标题最多 100 字、章节正文最多 100,000 字。字数按汉字数加英文单词数统计，不计标点和空白；章节正文超出所设目标字数时会显示提示，但不会丢弃生成结果。

作品列表按素材来源分为“文字灵感”“图片灵感”“小说改编”“原创文稿”。可按作品名称搜索、按所属项目筛选；列表显示节拍表/创意/剧本状态及版本号，状态包括未开始、生成中、待确认、已确认、失败、已取消，上游变更时标记“上游已变更”。“查看创意”打开产出页；编辑可更改名称、文本模型，创意阶段尚允许时可更改作品形态；图片灵感作品还可增删和排序图片。项目和素材来源不能编辑；修改图片不会自动重生成。删除作品前必须输入作品名称确认，作品素材、创意、剧本等内容会一起删除且无法恢复。

### 节拍表（可选）

节拍表把目标时长换算成每一拍的参考时长和字数，给后面的创作提供参考基准，可随时生成，不是必经步骤。

- 在作品列表的“节拍表”列点“生成节拍表”（已有记录时为“查看节拍表”）。表单字段：文本模型、节拍模板（按作品形态过滤，共 27 套，选中后说明里显示适用场景和节拍顺序）、目标时长（多集短片为单集目标时长；切换模板时自动改为该模板的默认时长，之后可手动修改）、集数（参考，仅多集短片）、语速（字/秒，可选）、创作主题或灵感（仅文字灵感作品）和补充要求。
- 每一拍的参考时长和字数由程序按模板比例计算，模型只给每一拍分配剧情内容；产出页里可编辑各拍的剧情内容，确认采用后才作为基准。
- 确认后：创意产出页“重新生成”里的“参考节拍表生成”按钮才会解除禁用，可以用它按节拍表重新生成；剧本和分镜阶段也会以它的目标时长为基准，偏差较大时自动重写几轮，仍有偏差时只提示，不阻止确认。

### 原创文稿：文字原样保留

“文字灵感”“小说改编”都会让模型重新创作，台词和描写会变。自己写好的文章要直接做成剧本时，用“创作 › 原创文稿”：

- 表单里上传 TXT / Markdown 文件或粘贴文字（二选一），点“创建并导入”。导入不调用模型：原稿按“设置 › 模型”的分段方式切成章节，文字原样保留，创意阶段直接是“已确认”，不需要再次确认。原稿不能超过 100 段，超过时调大每段字数上限或拆分原稿。
- 产出页里只能直接编辑章节正文，没有“重新生成”；编辑保存后需要再次“确认采用”。
- 原创文稿列表里只有“查看原稿”、修改、删除；生成和查看剧本都到“脚本 › 剧本”列表（点“添加”选作品），表单里没有“补充要求”。剧本正文就是原稿章节的拼接，不会被改写；模型只负责划分集（多集短片）、抽取角色等实体，并给每一集的正文做“结构标注”。单个短视频的正文不能超过 20,000 字。
- **结构标注**：把每一集正文切成片段（引号内外分开），标出每个片段是“旁白”“对白”还是“心声”，以及说话人。说话人只会从抽取出的角色（含别名）中选，对不上的标为“（未知）”并标记“待核对”。在集的编辑区可逐个片段修改类型和说话人，片段文字不会改变。
- 标注只是标签，不改原文：集的正文由程序按段落序号从原稿截取，模型不复制原文。修改某一集的正文并保存后，这一集的标注会被清除。在“剧本包正文”页点“重新标注”（仅确认前可用）可以保留集和实体、重做所有集的标注。
- 生成分镜脚本时，带标注的集会把“谁在说话”的标记一并提供给模型。

### 产出审阅页的共同操作

创意、剧本和分镜产出页顶部显示作品、阶段、模型、版本和状态：

- **待确认**：检查并编辑最新生成结果，确认采用后才可被后续阶段使用。
- **确认采用**：先看确认对话框中的影响说明，再确认。已有依赖数据的剧本或分镜可能会提示影响分集、实体、镜头或绑定。
- **重新生成**：打开原阶段表单并沿用上次参数；可更换模型或调整参数。存在未保存编辑时会先询问是否放弃。
- **取消生成**：只在生成中可用；取消后可根据状态重试或重新生成。取消不保证平台端停止计费。
- **重试**：对失败/已取消的阶段运行再次请求；若本次输入素材或小说分段设置与上次不同，创意阶段会提示从头开始。
- **版本下拉框**：查看各次生成记录；历史版本可读但不能编辑，选回最新版本继续修改。切换版本前未保存的编辑会要求确认是否放弃。
- **查看原始输出**：仅在系统保留输出时出现，用于查看模型原始返回内容，不会自动将输出应用到正文。

创意阶段左侧按章节列出标题、字数和字数提示；点章节后在右侧修改标题与正文，点“保存本章”保存。切换到另一章前若本章有未保存修改会提示。字数超出目标范围时会显示提示，但模型生成字数只是目标，章节仍会保留，可手工编辑调整。

## 剧本

在“脚本 › 剧本”点“添加”。若当前列表没有可生成作品，先回到“创作”列表完成创意并确认。选择作品后，设置文本模型、单集最大时长（1 至 3,600 秒）和补充要求（最多 2,000 字）；多集作品还可设置集数上限（1 至 100）。集数上限是上限，不会为了达到上限强行拆分。

生成剧本时会同时抽取分集和实体（角色、场景、道具、特效）。产出页左侧按“剧本包正文 / 集 / 实体”导航，右侧编辑选中项：

- **剧本包正文**：标题和梗概供查看，正文可修改并点“保存”。正文保存后，不会自动更新已抽取的集和实体；需要时点“重新抽取”。重新抽取会覆盖你手工修改的抽取结果，确认前会提示影响。
- **集**：多集作品可点“新增”创建分集；编辑集标题、梗概、目标时长和本集正文；点“上移”“下移”调整顺序或点删除。单个短视频固定只有一集，不能新增、删除或调整顺序。
- **实体**：可新增、编辑角色、场景、道具、特效的名称、别名、设定摘要及该类型专有设定，并可切换“启用”。新增实体可选择类型；切换类型会重置类型专有字段。多个别名用逗号分隔。
- 有未保存修改时，切换项目条目会询问是否放弃修改。生成中、失败、取消的阶段不能编辑；历史版本只读。
- **改编取舍**：作品有已确认的节拍表，且创意内容的预计时长明显超出目标时长（多集短片为单集时长乘集数）时，剧本阶段会先暂停，列出可删减的支线、可合并的人物、可跳过的场次，各自标注理由、预计节省秒数和涉及的章节、场景或人物，默认按模型建议勾选。勾选变化时页面实时重算预计总时长（不调用模型），点“确认取舍并生成正文”后才生成剧本；生成后的剧本会注明按几项取舍生成。

剧本包正文最多 200,000 字；分集标题最多 60 字、梗概最多 1,000 字、本集正文最多 20,000 字，目标时长可留空或填 1 至 86,400 秒的正整数。实体名称最多 50 字、别名最多 10 个、设定摘要和每项设定最多 500 字；实体总数最多 200 个。超过限制时保存会失败并显示字段错误。

已确认采用的剧本版本被修改、删除集/实体或重新抽取时，保存可能使阶段退回“待确认”，需再次确认后才能供下游使用。删除集会使后续集序号前移；若旧集已有分镜，相关分镜可能一并删除，操作前的确认提示会说明影响。已被镜头、声音或资产绑定引用的实体不能删除，可改为停用。确认剧本时，若要移除的旧集仍有关联分镜、绑定或参数，确认会被阻止；请先在新版本中保留需要的集。

## 分镜

在“脚本 › 分镜”点“添加”，选择剧本已确认的作品。多集作品可一次选择多集并行生成。

| 选项 | 作用 |
| --- | --- |
| 视频模型、画幅、分辨率 | 选择后保存为作品默认参数，工作台会沿用；可选值受模型能力限制 |
| 画面风格 | 留空时沿用项目视觉风格 |
| 单镜头时长范围、镜头总数上限 | 控制镜头节奏和数量 |
| 单组最长时长 | 将相邻镜头按顺序打包成镜头组；不能超过模型单次生成时长上限 |
| 连贯策略 | 组间硬切（推荐，默认）、无、尾帧接首帧或由 AI 判断是否接尾帧 |
| 声音模式与内容 | 无声或模型原生生成；可选择对白、旁白、音效和背景音乐 |

较长剧本会按场次分批生成；使用“第 N 场”格式的场次标题有助于分批识别。生成选项包括目标视频模型、画幅、分辨率、画面风格、每镜头时长范围、镜头总数上限、单组最长时长、镜头连贯策略、声音模式与声音内容、补充要求。选项留空时通常继承项目风格/默认画幅/分辨率或模型默认值；模型能力以表单当前可选值为准。

分镜数上限为 1 至 200、单镜头时长支持 0.1 至 600 秒且最多 1 位小数、单组最长时长为 2 至 120 秒（默认 15 秒），并且不得超过目标模型的单次时长上限。连续策略可选组间硬切（默认，组与组之间切换景别和机位，不用尾帧，每组都保留参考图和音色）、不衔接、上一镜头尾帧（会丢失该组的参考图和音色）或由 AI 判断是否接尾帧（画面连续处接尾帧，场景或时间变化处不接）；分镜编辑页和分镜动画的检查列表会提醒“硬切处景别和机位都没变”、“接尾帧会丢掉参考图和音色”，只提醒不阻止提交；声音模式可选“无声”或“模型生成声音”，声音内容包括角色对白、旁白、音效、背景音乐。无声模式下声音内容设置会被忽略。

在分镜产出页，顶部显示镜头数、总时长、分组数等汇总；左侧点镜头切换（也可用底部的“上一个”“下一个”），右侧编辑所选镜头，分“调度”“镜头”“画面与声音”三个页签：“调度”左侧点实体名称切换是否出场、右侧为每个出场的角色、道具、特效设置起点（画面左外、左侧、中央、右侧、右外，加前景、中景、背景）、终点（不填表示不移动）、朝向和动作，位置与朝向以观众看到的画面为准，场景不需要站位，生成视频时会自动写进提示词（面板较窄时左右两部分上下排列）；“镜头”可编辑场次、时长、景别、机位与视角、摄影机运动、转场、连续性要求，并设置首帧来源（不指定、上一镜头尾帧、指定图片、资产参考图）；“画面与声音”可编辑画面描述并管理声音。三个页签的修改一起保存，切换页签不会丢失已输入的内容；有未保存修改时标题行右侧显示“有未保存的修改”，点底部的“保存镜头”保存。对白的说话人会自动列为出场实体。画面描述是发给视频模型的画面正文，第一句概括主体与动作（同时用作左侧列表标题），再按主体、场景、运动、审美控制描述；镜头字段会自动合并。

声音条目可添加、编辑、启用/停用、上移、下移或删除；声音类型为角色对白、旁白、音效、背景音乐。对白可选择说话角色，填写台词、说话方式、开始时间和时长；其他声音填写声音描述。每镜头最多 20 条声音，台词/声音描述最多 500 字，说话方式最多 200 字；开始时间可留空或填 0 至 600 秒，时长可留空或填大于 0 至 600 秒。声音模式为“无声”且没有声音条目时会显示相应说明。镜头可新增（左侧列表标题行的“添加”，填写后点底部的“添加镜头”）、保存、删除、上移或下移（后三项在编辑区右上角）；删除确认会说明镜头声音也会删除以及镜头序号会前移。

镜头主要字段限制：画面描述必填、最多 2,000 字；场次、景别、机位与视角、摄影机运动、转场各最多 100 字；连续性要求最多 500 字；时长须为 0.1 至 600 秒且最多 1 位小数。保存时报错时按字段提示修正。

分镜动画预览：分镜生成成功后，可以在正式生成视频之前把整集分镜播放成简化动画，先看节奏和调度。打开方式有四种：分镜产出页头部的“分镜动画”按钮；镜头编辑区右上角的“从此镜头预览”（从当前选中的镜头开始）；分镜列表操作列“查看分镜”右侧的“分镜动画”按钮（单个短视频直接播放那一集，多集短片先弹出各集列表再选集）；各集分镜脚本状态列表里的“动画”按钮。生成中、失败、已取消或没有镜头时这些按钮不可用。分镜脚本页面和预览都是非模态的弹出层，不会挡住其他页面，可以同时存在并拖到一边对照；同一集只打开一个，重复打开会聚焦已有的。查看历史版本时预览的是该版本，并显示“历史版本”标记；否则预览最新版本。作品没有记录画幅时按 16:9 显示并有提示。

预览的画面：角色默认是矢量小人（同一角色衣服颜色一致，第一个角色为红色），角色不是人时按角色名称（名称认不出再看“身份”和设定开头的介绍，如“是一只松鼠”）画成对应的样子：动物有松鼠、刺猬、鼠、兔、猫、虎、狮、豹、狗、狼、狐、熊、熊猫、河马、鹿、长颈鹿、马、斑马、独角兽、骆驼、驴、牛、羊、猪、蛙、大象、犀牛、猴、猩猩、袋鼠、鳄鱼、乌龟、蜥蜴、恐龙，鸟类有鸡、鸭、鹅、猫头鹰、鹦鹉、企鹅、鹰、孔雀、鸵鸟和其他鸟，另有蝙蝠、鱼、鲨、鲸与海豚、章鱼、水母、螃蟹龙虾、海星、蛇，昆虫和小虫有蝴蝶、蜜蜂、瓢虫、蚂蚁、蜘蛛、蜻蜓、蜗牛、蚯蚓、甲虫和其他昆虫，微生物有病毒、细菌、真菌、变形虫（带脸的放大示意），其他动物用通用兽形；奇幻角色有僵尸（绿皮、双臂前伸）、神仙与天使（光环、长袍、悬浮）、精灵（翅膀、尖耳）、怪物与巨龙（高大、犄角、獠牙）、邪灵与幽灵（半透明飘浮）、恶魔（红皮、犄角、翅膀、尾巴）、机器人；认不出的都画成人。马、牛、熊、鹿等容易是姓氏的单字只在作为名称最后一个字（如“小熊”“老马”）或设定写明“是一只…”时才算动物，所以“马老师”仍是人。人会区分性别和年龄：名称里有“奶奶”“爷爷”“小女孩”“小男孩”“婴儿”“公主”等称呼，或设定开头写了“女性”“男，72 预览的操作：播放/暂停、上一镜（本镜头已播放超过 1 秒时回到本镜头开头）、下一镜、回到开头、循环当前镜头、倍速（0.5×、1×、1.5×、2×）；显示选项可开关名称、动作、轨迹与朝向、站位网格、字幕、画面描述、景别与运镜、取景框，默认只关闭站位网格。预览上方可在三种视图间切换：“舞台”是动画；“镜头对照”把上一镜结尾、本镜开头、本镜结尾三幅静态画面并排显示，第一个镜头没有上一镜，用来检查镜头之间的衔接；“调度俯视图”从上往下看 5×3 站位网格和画面范围，标出本镜头每个实体的起点（空心）、终点、虚线走位、此刻位置（实心）、朝向，以及上一镜终点到本镜起点的灰色虚线，位置跳变一眼可见。底部时间线按镜头时长分段，用“组 N”标出镜头组，下方是对白、旁白、音效、音乐的声音泳道，有警告的镜头下沿有警示线；点击或拖动即可跳转。键盘：空格播放/暂停，左右方向键后退/前进 1 秒，Shift 加左右方向键切换上一镜/下一镜，Home 和 End 跳到开头和结尾。右侧显示当前镜头的场次、景别、机位、运镜、转场、时长、所属组、首帧、画面描述、调度和声音，窄宽度时移到舞台下方。

预览的检查：右侧信息栏按页签分为“镜头”“画面”“调度”“声音”“检查”，点页签切换，调度、声音、检查页签后显示数量；“检查”页签列出问题，点一项跳到该镜头，点右侧的“在分镜里编辑”打开分镜产出页并定位到该镜头。警告包括：声音超出镜头时长、台词语速过快（给的时长不够说完）、同一镜头两条人声重叠、说话人没有站位、以上一镜头尾帧为首帧但角色起点与上一镜头终点相差太远；提示包括：角色整个镜头都在画面外、近景或特写只对准说话的角色而另一个角色被拍到画面外（画面里看不到，调度列表里该角色会标“不在取景范围内”）、同一场景里相邻镜头位置衔接不上、没有出场角色、镜头时长不足 1 秒或超过 10 秒、运镜无法模拟。保存分镜后预览自动刷新，并保持在同一镜头附近，不打断播放。预览不代表最终画面，默认不调用模型、不产生费用，也不能在预览里编辑；手册没有记载导出预览视频的能力。

台词配音（预览里听对白）：预览视图切换行下面有一行“台词配音”，包含声音模型下拉、“播放时配音”开关、“合成本镜头配音”和“合成整集配音”按钮和三行信息（统计：本镜头与整集已合成条数、需要合成的条数；合成进度：只在合成期间显示；提示：结果与失败原因，拖动进度条、切换镜头不会清除）。可以试听的是角色对白和旁白，且说话人已有音色：角色在“生成工作台 > 绑定素材”里已绑定音色参考（主资产），旁白已有作品的旁白音色，或用着下面“生成音色”得到的临时音色；这样的台词在右侧“声音”页签的列表里带“试听”按钮，点击会调用所选的声音模型合成这句台词并播放；没有音色的说话人显示“X还没有音色”和“生成音色”按钮，音效、配乐不配音。声音模型下拉只列“模型设置”里服务商已启用、已填访问密钥、模型已启用且能生成语音的音频模型（如豆包语音合成 2.0、千问音频 3.1），选项文字为“服务商 · 模型名称”，默认选第一个；没有可用模型时没有下拉，该行提示“还没有可用的声音模型”并说明要到“模型设置”启用音频服务商、填写访问密钥、启用支持语音的音频模型，试听按钮不出现；在“模型设置”里启用或关闭模型、改访问密钥后，动画里的下拉列表会实时刷新，不用重新打开，所选模型被关闭时自动改选第一个。所选模型支持参考音频（如千问音频）时，用角色绑定的音色参考，并把对白的说话方式写进提示词合成；不支持参考音频（如豆包语音）时，按角色固定选一个预置音色，说话方式换成语音指令，并从“语速偏慢”“悄悄话”“大喊”等文字里读出语速和音量一并调整，状态文字会提示“所选模型不支持参考音频，按预置音色试听，与绑定的音色参考不同”。声音列表里对白下方会显示它的说话方式，没写说话方式的会提醒“按默认语气合成”。“合成本镜头配音”依次合成当前镜头所有可试听的对白并显示进度，“合成整集配音”合成整集所有可试听的对白（先弹出确认提示费用）；“重新合成本镜头”“重新合成整集”忽略已合成的结果，重新调用模型合成并替换旧的（同样先确认，会产生费用，想换一种读法时用）；勾选“播放时配音”后，动画播放到对白开始时间就同步播放它已合成的配音：自动跳过合成语音开头的静音；配音比留给它的时间（到下一条人声开始、镜头结束或自己的时长）长时，播放时适当加快，最多 1.4 倍，不改变合成的音频；多条配音按各自的开始时间同时出声（对白、旁白叠放），不互相截断；播放中勾选或取消“播放时配音”立即生效，勾选时正在说的配音从当前位置接着播；拖动进度条到某句对白中间也从该位置接着播（已说完的不播）；暂停时一并暂停，回退或跳转后重新计，倍速同步；播放时不会触发合成，没合成过的对白不发声。费用与重新合成：每次合成都会调用模型并产生费用；修改了台词、说话方式、角色的音色绑定（换了音频）或换了声音模型后，再点“试听”或“合成本镜头配音”才会重新调用模型，没有变化的对白直接使用已合成的结果，状态文字提示“没有重新调用模型”；修改并保存台词不会自动合成。合成结果会保存在本地（数据目录下的 voice-cache，最多 500 条、约 1 GB，超过后淘汰最久没用的，不在数据备份内），关闭预览再打开、重启应用后，打开预览时会自动把本集已合成的配音读回来（只读本地，不调用模型，不产生费用），直接勾选“播放时配音”即可听。台词或说话方式改过的对白读不到旧结果，声音列表里会标“需要合成”，状态文字会列出需要合成的条数，不会自动重新合成，要点“合成本镜头配音”“合成整集配音”或“重新合成”。失败时（如没有访问密钥、额度不足、内容审核）状态文字显示平台返回的原因。

生成音色（说话人没有音色时）：角色或旁白还没有音色时，声音列表里点“生成音色”打开对话框，让声音模型按剧本里的音色描述生成一段试听音色，满意后采用，之后动画里这位说话人的台词就用这个音色播放。对话框里依次是：声音模型下拉；“音色描述”（角色取设定里的音色设定，没有时取身份与概述，可以修改，只用于这次生成，不改剧本；旁白没有设定，需要自己写，例如“沉稳的中年男声，语速偏慢”）；“试听台词”（默认是点开时那一条台词，最多 120 字）；“生成试听”按钮，生成后可以点“试听”听效果，不满意点“换一个”重新生成。生成的是临时音色，只在动画预览里使用，生成后立刻可以“合成本镜头配音”用它试听，台词旁显示“临时音色”和“采用…”；点“采用并绑定”（对话框里或台词旁的“采用…”）才会把它保存为一个“音色参考”音频资产并绑定：角色绑定到当前集（可勾选“同时用于本作品其他 N 集”，只对这些集里还没有该角色音色的有效，已有音色的集不会被覆盖），旁白设为作品的旁白音色（作品里所有集共用，已有旁白音色的会被替换，之后可在旁白台词旁点“更换音色”再生成）。资产名称默认是“角色名·音色”（旁白为“作品名·旁白”），不能和已有的音频资产重名，重名时在名称下提示，改名后再采用。两种模型的区别：支持参考音频的模型（千问音频）按描述生成，采用后这段样本就是该角色的参考音频，其他台词都以它为参考合成，声音保持一致；只有预置音色的模型（豆包语音）不能按描述生成，对话框改为选一个预置音色，采用后音色名记在资产里，之后合成就用这个音色。每次点“生成试听”“换一个”都会调用声音模型并产生费用，不点不会调用；试听音色只暂存在应用运行期间的内存里，重启后需要重新生成，采用后才永久保存。角色在本集已经绑定了音色时不能再采用临时音色。

点击“确认采用”前会显示受影响信息；确认后分镜才供工作台生成视频。已确认的分镜再编辑、添加或删除镜头后，会退回待确认。阶段页顶部可切换版本；查看历史版本时不可编辑。失败记录可查看保留的“模型原始输出”，必要时重试、取消生成或重新生成。放弃未保存的编辑时需确认。剧本修改后，分镜会标记“上游已变更”。

AI 生成来源的新建表单在设定字段之后有“生成方式”下拉，点“仅创建”只保存设定，点“创建并生成”按所选方式继续：

| 生成方式 | 行为 |
| --- | --- |
| 直接出图（音频为“直接生成音频”，默认） | 按已填设定用固定模板拼出提示词并立即生成，不调用文本模型；图像类至少要填一项视觉描述，音频需要描述 |
| AI 生成提示词 | 由文本模型在后台生成提示词，不自动生成；检查提示词后到列表里点“生成图片/生成音频” |
| AI 生成提示词并出图 | 文本模型生成提示词成功后自动生成；从实体新建资产时默认选这一项 |

选“直接出图”或“AI 生成提示词并出图”时，表单里还要选图像（音频）模型，图像类可选生成数量和分辨率，音频可选预置音色；图像的画幅取“参考图画幅”，音频的语言取“语言”，所选模型不支持时会提示换模型或取值。选带 AI 的两项时还要选文本模型；没有启用任何文本模型时带 AI 的两项无法创建，需先到模型设置启用文本模型或改选“直接出图”。创建过程中若实体绑定或直接提交出图失败，刚创建的资产会回滚；提示词在后台生成失败时，资产保留并可重试。“AI 生成提示词并出图”的自动出图失败时，资产和已生成的提示词都会保留，列表“提示词”列显示失败原因，可直接点“生成图片”重试；提示词生成期间修改了资产设定时不会自动出图，列表显示“需更新”。没有保存提示词的资产，列表“提示词”列显示“使用模板”，生成时按设定实时拼出提示词。

编辑表单可选“保存”或“保存并重新生成提示词”；后者会启动后台提示词生成，若已有提示词需确认覆盖。上传来源保存时直接写入文件并切换为上传来源。资产类型创建后不能修改；分类可在编辑表单中变更。

上传与生成两种来源的文件都会保留。在“使用的文件”列点“改用上传”或“改用生成”只切换当前使用来源，不删除另一种来源。绑定和视频提交均使用当前来源；还未上传过文件时，“改用上传”会打开上传表单。若音频已用作角色音色参考，切换到没有音频文件的来源前要先解除引用或提供文件。

### 资产列表、分类和删除

资产列表可搜索名称、按“全部”“未分类”或指定分类过滤。图像缩略图可点开看原图，音频可试听。通过“分类管理”打开当前资产类型专用的分类表，可创建、修改或删除分类；分类名称在同类型内唯一。删除分类时会显示资产数，确认后这些资产保留但变为未分类。

删除资产前会显示它被哪些作品、分集实体绑定或镜头声音引用；确认删除后，资产本身、对应文件及绑定会一并清除且无法恢复。先检查使用位置；如果还要使用，取消删除并解除相应引用。

### 提示词与图片/音频版本

AI 生成来源可在列表点“提示词”查看和编辑提示词。修改资产设定后，列表会显示提示词可能需更新；保存手工改动即视为已确认。提示词生成中不可编辑；失败或取消可点“重试提示词”，生成中可点“取消提示词”。重新生成已有提示词会先要求确认覆盖；表单中未保存的手工修改会丢失。上传来源没有提示词功能。

点“生成图片”或“生成音频”：

1. 选择已启用且能力可用的模型；如果不可生成，先按对话框提示检查密钥、服务商和模型开关。
2. 图片可选生成数量（不超过该模型上限）、支持的画幅和分辨率，并可勾选是否发送已有参考图。留空画幅使用资产参考图画幅，留空分辨率由模型决定。
3. 音频每次生成 1 个，可选模型支持的音频语言和预置音色；没有选择时由模型决定。
4. 点“生成图片”或“生成音频”提交。失败时对话框保留并显示原因；成功后结果保存为新版本，不会自动替换当前使用文件。每次提交按平台计费；图片生成任务不能从资产列表取消。

点“版本”查看版本列表和状态。版本详情可查看生成时使用的模型、提示词、语言、数量、画幅、分辨率及提交/结束时间。图片可以看原图，音频可以试听。生成失败会显示平台错误分类、原文和建议；失败或取消的版本可“重试”，也可在版本页开始新生成、编辑提示词。

选择生成成功且文件完整的版本后，点“采用此版本”；有多张图片时按界面选择需采用的结果文件。采用后该版本才会成为资产的生成来源文件。活动中的版本不能删除，当前采用中的文件不能直接删除；可先采用其他版本或改用上传文件。设定或提示词在版本生成后改动时，版本页会提示该版本依据旧内容生成。

角色可绑定音频资产作为音色参考，并可在绑定页面试听。被角色用作音色参考的音频不能切换到没有文件的来源；需先解除绑定或准备好文件。

## 视频生成工作台

从“视频 › 生成工作台”进入，也可点击生成完成通知中的“打开工作台”。在顶部依次选择项目、作品和分集；更换项目或作品时会回到该作品第一集。选择有分集记录的作品；若分镜尚未确认，工作台会显示阻断提示，不能提交生成任务。工作台包括镜头组列表、镜头组详情、绑定素材/配置参数/检查并提交三个步骤，以及可折叠的“队列与结果”。

镜头组可能显示待绑定、可生成、等待前序、排队中、生成中、已完成、失败或已取消等状态。详情中可查看镜头、出场实体和生成状态；可以在指定镜头前拆分镜头组、并入上一组，或按新的单组时长重新分组。重新分组会清除各组已有生成记录，但不会删除已保存的视频文件。

### 绑定素材

选择左栏镜头组后，“绑定素材”只显示该组镜头出场的实体。上方“按名称自动匹配”只建议该组实体与同类型同名称资产的匹配，检查建议后确认应用；没有自动匹配到的实体可手动处理。实体未绑定也可按文字描述生成，但不能利用参考图。

对某个实体点“选择资产”，在弹出的资产选择页按名称搜索，检查缩略图后点“选择”；没有合适资产时点“新建资产”，按实体设定新建并自动绑定为形象。一个实体可绑定多个形象资产，选择“设为主资产”指定主参考；点“解除”移除单个绑定。点击缩略图可查看原图。

角色还可单独选择“音色参考”音频并试听；没有指定音频时只使用角色设定中的文字音色。形象与音色绑定是不同用途，不能用音频资产替代形象参考图。组内实体绑定全部完成后，页签显示“全部已绑定”；部分未绑定会显示未绑定数量。

### 配置生成参数

在“配置参数”步骤，从“作品默认”“本集”“本镜头组”三个范围中选择要编辑的层级。实际生效值从镜头组覆盖、本集覆盖、作品默认逐级继承，再参考项目默认或模型默认；界面逐项显示来源。留空或点“恢复沿用上一级”可撤销该级覆盖。保存后顶部会更新当前生效参数摘要。

| 参数 | 说明 |
| --- | --- |
| 视频模型、画幅、分辨率 | 可选值受模型能力限制 |
| 声音模式、声音内容 | 可选对白、旁白、音效、配乐；模型不支持的类型会置灰 |
| 随机种子 | 留空表示随机；填写 0 至 2,147,483,647 的整数。不支持该参数的模型会置灰 |
| 负向清单 | 提示模型避免指定内容，例如“不要字幕，不要水印”；最多 300 字，清空表示不使用 |
| 提示词改写 | 控制是否让平台改写提示词；关闭后使用编排后的提示词。模型不支持时会置灰 |
| 本组生成时长 | 仅镜头组级别可设置；不得小于镜头总时长，且必须符合模型时长范围。留空时按镜头总时长向上取整 |

具体填写步骤：

1. 先选择模型；模型会决定可选画幅、分辨率、声音模式及支持的随机种子/提示词改写选项。
2. 选好画幅、分辨率；声音模式选“无声”或“模型生成声音”，再设置对白、旁白、音效、配乐。置灰的选项表示模型不支持。
3. 根据需要填写随机种子、负向清单和提示词改写开关；留空的参数沿用上一级或模型默认值。
4. 若只想让个别集或镜头组使用不同参数，在对应范围设置覆盖；其他项目留空继承上层。确认模型和参数页签无“无可用模型”或“需调整”提示后再进入提交步骤。

### 检查并提交

进入“检查并提交”后逐组勾选要生成的镜头组；可点“全选”“仅未完成”或“清空”。“仅未完成”不会选择已有成功结果、当前生成中或超出模型时长上限的组。

提交前的检查会预览镜头组、实际参数、参考图数量和最终提示词，并列出阻断问题和提醒，例如实体未绑定、参数超出模型范围或声音类型不受支持。点开“将提交的提示词”可核对即将发送的内容。阻断问题必须取消勾选该组或先返回处理；有提醒时须勾选“我已了解以上提醒”。若分镜脚本尚未确认、模型不可用或参数仍有错误，不能提交。

点“提交所选（数量）”后任务进入队列。单次最多提交 100 个镜头组。提交失败或所选镜头组全部被拒绝时，勾选状态会保留，修正后可再次提交。生成通常需要数分钟；完成或失败时会显示通知。

### 队列与结果

- 可取消排队或生成中的任务，也可重试失败任务。失败项会显示原因和处理建议。
- 同一镜头组有任务正在生成时不能再次提交；完成或取消后才可重新提交。
- 结果支持用系统播放器播放、导出或在文件夹中显示。
- 每次提交的结果会作为一个版本保留；首个成功结果自动采用。存在多个成功版本时，可在“结果版本”中比较参数和提示词差异并采用其他版本。
- 任务行会显示模型、状态、耗时（生成中每秒实时刷新）、尝试次数、失败分类及等待提示；点任务行中的镜头组可定位到详情。失败或取消的最新任务可重试，生成中或排队中可取消。
- 取消生成中的任务需确认；若平台不支持远程取消，应用会停止等待，但平台任务仍可能继续并计费。通知平台取消失败时，界面会显示原因。
- 结果支持“播放”（用系统播放器打开）、“导出…”到指定位置和“在文件夹中显示”。导出完成后会显示通知。
- 镜头组有多个成功结果时点“结果版本（数量）”，可逐个打开、导出、定位文件夹、采用版本，或勾选两个版本点“对比”。对比页比较生成参数、结果信息和提示词；视频画面需点“播放”在系统播放器中比较。

### 镜头连贯与首帧

**使用上一组视频尾帧**：把本组第一个镜头设置为“上一镜头尾帧作首帧”。本组会等待上一组生成成功，再截取其最后一帧作为首帧。

- 截取尾帧时需保持工作台页面打开；关闭期间任务会停在“等待前序”，重新打开后继续。
- 使用尾帧作首帧时，本组不再传实体参考图和音色参考。
- 上一组重新生成并采用新版本后，依赖旧尾帧的后续组会提示可能不连贯，不会自动重生成。
- 上一组失败或取消时，等待它的任务也会失败；待前一组成功后需重新提交。

**指定图片作首帧**：在“编辑镜头”中把镜头组第一个镜头的“首帧来源”设为“指定图片”，点“选择图片”上传一张本地图片（PNG、JPEG、WebP，不超过 10 MB），例如自己截取的上一段视频尾帧。图片保存在本地，之后再打开该镜头仍会显示缩略图，点缩略图可查看原图；重新选择图片即可更换，点“移除”后需要重新选择图片才能保存，改用其他首帧来源则会删除已保存的图片。提交时使用这张图片作首帧。

**资产参考图作首帧**：把“首帧来源”设为“资产参考图”，再从资产中选择至少有一张参考图的角色、场景、道具或特效资产。提交时使用该资产第一张参考图，资产更换参考图后首帧随之更新；资产被删除或没有参考图时该组无法提交。

- 仅对镜头组第一个镜头生效；该组不依赖上一组，可以直接提交。
- 使用指定图片作首帧时，不再传实体参考图和音色参考；所选模型必须支持首帧输入。
- 若资产被删除或失去参考图，该组无法提交；请重新选择资产或改回不指定首帧。

### 调整镜头组

- 在详情里点“编辑镜头”可打开本集分镜产出页并定位到该组第一个镜头；修改分镜内容后保存并重新确认分镜脚本，再返回工作台提交。
- 在镜头列表某镜头前点拆分操作，可将该镜头及其后镜头拆到新组；“并入上一组”会把当前组并入前一组。
- 有任务记录的镜头组不能拆分或并入上一组；需要先处理生成记录，再调整布局。
- 左栏底部填写“每组最长”秒数并点“重新分组”，可依镜头顺序重新打包。时长必须是整数并符合模型范围；有任务进行中时不能重新分组。若已有任务记录，确认框会说明本集镜头组和生成记录将清除，已保存视频文件不会删除。
- 更换结果版本时，如果下一组已采用依赖当前组尾帧的视频，会先提示两组可能不连贯并要求确认；下一组不会自动重新生成。

## 数据备份与恢复

打开“设置 › 数据备份”可查看数据库位置、大小、版本和各类数据数量。

### 创建备份

1. 点“备份到文件”，在系统文件对话框选择保存目录和文件名。
2. 等待操作完成并查看页面结果；备份内容包括项目、作品、剧本、分镜、资产和参数。
3. 资产、镜头首帧、尾帧的图片与音频，以及上传的灵感图片、小说、原创文稿等本地文件保存在备份文件旁同名 `.files` 文件夹中，例如 `xxx.sqlite.files`。复制到其他设备或归档时必须将备份文件和这个文件夹一起复制。

### 恢复备份

1. 点“从文件恢复”，在系统文件对话框选择备份文件。
2. 检查备份版本、校验结果和缺失的本地文件数量；确认备份文件与同名 `.files` 文件夹位于同一目录。
3. 点确认执行恢复。此操作会用备份替换当前数据库，恢复前系统会先自动备份当前数据；完成后按提示重启应用。点取消则不恢复。
4. 高于当前应用版本的备份不能恢复。恢复时只补充缺失的本地文件，不覆盖或删除已有文件；找不到的文件会提示，对应图片、音频或素材恢复后无法使用。

备份不包含视频结果文件或访问密钥。需要保留视频时，请自行复制工作台显示的结果视频目录；恢复后若访问模型，需重新配置密钥。

如果数据库无法打开，左侧菜单会显示原因及“数据备份（恢复）”入口。此时其他功能不可用，也不能创建新备份；可选择已有备份并确认恢复。替换前无法打开的数据库文件会先自动备份，恢复后重启应用生效。

## 费用与限制

- 服务商的文本模型生成文字，以及生成图片、音频和视频均可能产生平台费用，请遵循千问AI平台、火山引擎、豆包语音和 MiniMax 当前的计费规则。
- 若平台不提供任务取消接口，取消只会停止本地跟踪，平台任务可能继续运行并计费。若通知平台取消失败，界面会显示原因；请到平台控制台确认任务状态。
- 单个结果视频不超过 200 MB；超过时无法保存或在工作台读取。可缩短时长或降低分辨率后重新生成。
- 单组最长时长、画幅和分辨率取决于所选模型；模型专有参数目前未开放。
- 当前集成千问AI平台、火山引擎、豆包语音和 MiniMax 四个服务商的模型。

## 常见问题与故障排查

### 安装、入口和列表

**安装后打不开或找不到如见 Studio**  
确认安装已完成：重新运行安装包，再从开始菜单或桌面快捷方式打开。仍然无法启动时，记录错误提示或现象，不要删除数据库文件。

**列表为空、加载失败或找不到项目/作品/资产**  
检查当前列表类型、作品所属项目筛选、资产分类筛选和搜索关键词；清除筛选后再查找。列表报错时先读页面错误并点“重试”。数据已被删除时，只有已有备份可用于恢复。

### 模型、密钥和文本生成

**模型选择列表为空或提示没有可用模型**  
到“设置 › 模型”检查相应服务商已启用、访问密钥已配置、所需模型已启用。模型默认都不启用，需要在服务商设置里逐个启用；文本模型要启用服务商的文本模型，图片/音频/视频则检查对应类型模型。具体模型能力以模型设置页为准。

**“测试连接”失败或模型返回鉴权错误**  
确认访问密钥属于所选服务商、未过期且账号可用；确认各接口地址填在对应模型类型的字段中（软件不校验网址格式）；火山引擎与豆包语音的密钥不通用，需分别配置。必要时重新保存密钥并再测试。只向支持人员提供“已配置/未配置”和脱敏错误，不能发送密钥。

**创意、剧本、分镜或提示词无法生成**  
文本生成确认服务商的文本模型已启用并配置服务商密钥。表单中确认实际选中的文本模型仍可用；作品指定的文本模型不可用时，到模型设置更换作品文本模型或本次选择。

**提示词生成被禁用**  
上传来源资产没有 AI 提示词入口；生成来源需要满足资产字段要求。“生成图片/音频”按钮不可用时看悬停提示：没有保存提示词且设定不足（图像类至少一项视觉描述，音频需要描述）时无法生成，补充设定或到“提示词”页手动填写、生成提示词即可；设定足够时不填提示词也可以生成，会按模板拼出。

### 创意、剧本和分镜

**不能新建作品**  
先在“项目 › 所有项目”至少创建一个项目；作品名必须在所属项目内唯一，按表单提示修正重名或必填字段。

**“生成剧本”不可用**  
只能选择创意已生成并确认采用的作品；回到创意产出页检查最新状态并确认采用。

**“生成分镜”不可用或工作台不能提交**  
剧本必须先确认采用，且该集要有已确认的分镜脚本。检查作品/分集选择、模型是否可用、镜头组是否有阻断问题；工作台的“检查并提交”会标明需要处理的项目。

**显示“上游已变更”**  
表示创意或剧本等上游阶段修改后，下游结果可能已过期。重新生成并确认采用对应下游阶段，再继续后续制作。

**阶段正在生成、失败或历史版本时不能编辑**  
生成结束后编辑最新成功版本；失败时按错误原因重试或重新生成。历史版本是只读的，切换到最新版本后再编辑。切换版本或条目前先保存，或确认放弃未保存修改。

**正文修改后分集/实体没有变化**  
保存剧本包正文不会自动更新抽取结果；在正文编辑区点“重新抽取”。该操作会覆盖已有分集和实体修改，先检查确认提示。

### 资产、上传和版本

**上传图片或音频被拒绝**  
检查扩展名、单文件大小、文件数量和音频时长：图片为 PNG/JPEG/WebP，每张不超过 10 MB，且最少 1 张；音频为 MP3/WAV/M4A、不超过 20 MB 且时长不超过 60 秒。确保文件未损坏并可解码。

**资产生成按钮不可用或结果没有切换**  
上传来源没有 AI 生成按钮；生成来源需有可用模型与可用的提示词（已保存的，或设定足够按模板拼出）。图片/音频生成成功只新增版本，不会自动采用；到“版本”页查看结果并点“采用此版本”。

**列表显示“有改动未生成”或提示词需更新**  
修改资产设定不会修改已有提示词或生成结果。到“提示词”页检查并保存或重新生成提示词，再提交新图片/音频版本并按需采用。

**自动匹配没有绑定某实体**  
按名称自动匹配只针对当前镜头组中出场实体的同名资产；检查资产类型和名称。没有匹配项时手动“选择资产”或按实体设定“新建资产”。未绑定资产仍可按文字描述生成，但不会使用参考图。

**删除正在使用的资产或切换音频来源前要确认影响**  
删除资产并非一概禁止，但会一并清除其文件和绑定；先检查确认框列出的作品、分集、实体绑定和镜头声音引用。角色音色参考仍被使用时，不能切换到没有音频文件的来源。

### 视频任务和结果

**按组提交被阻止**  
先检查分镜已确认、模型可用、参数在模型能力范围内、镜头组时长未超限，并解决“阻断”问题。若有提醒，勾选“我已了解以上提醒”；超过单次模型时长可拆组或换模型。

**任务失败**  
工作台会显示失败分类、平台错误原文、错误码（如有）和建议。按界面分类排查：

| 界面分类 | 处理步骤 |
| --- | --- |
| 密钥或账号问题 | 到“设置 › 模型”检查密钥、服务商和账号/额度状态，测试连接后重试 |
| 请求被限流 | 等待一段时间，避免连续提交，再重试 |
| 参数不符合要求 | 按模型能力检查画幅、分辨率、时长、种子、声音模式和素材数量 |
| 内容审核未通过 | 检查镜头画面描述、对白/旁白文本及参考素材；修改后保存并重新确认分镜，再重新生成 |
| 服务端错误 | 按界面建议稍后重试；多次失败时保留分类、错误码和平台原文供进一步排查 |
| 网络错误 | 检查网络和服务商连接，点“测试连接”后重试 |

**等待上一组尾帧的任务失败或停留在“等待前序”**  
确认上一组已有成功结果，并保持工作台打开以便截取尾帧。若上一组失败/取消，先重新生成上一组，再重新提交当前组。尾帧截取失败时查看失败提示；可把本组首帧来源改为“不指定”或改用指定图片。

**取消后任务仍在平台运行或继续计费**  
取消会停止应用等待结果；若服务商不支持远程取消，平台任务仍可能继续。若界面提示通知平台取消失败，到服务商控制台检查任务并留意费用。

**结果没有保存、播放或打开失败**  
检查结果文件是否超过 200 MB；超限时缩短单组时长或降低分辨率后重新生成。使用“导出…”可另存结果；备份恢复不包含视频文件，因此恢复旧备份后视频记录可能与磁盘文件不匹配。

**采用新版本后相邻镜头可能不连贯**  
如果下一组采用的视频使用当前组旧版本尾帧生成，切换当前组版本不会自动重生成下一组。按确认提示决定是否接受；需要连贯时重新生成后续组。

### 数据备份和恢复

**所选文件不能恢复**  
确认选择的是本应用导出的数据库备份，而不是视频、普通数据库或其他文件。损坏文件不能恢复；备份结构版本高于当前应用时先升级应用后再试。

**恢复后资产图片/音频缺失**  
把备份文件和同名 `.files` 文件夹放在一起再恢复。恢复仅补充缺失文件，不覆盖或删除现有文件；备份时未带上的文件无法由恢复操作找回。

**恢复后视频不见或与旧记录不一致**  
备份不包含结果视频文件。恢复前复制结果目录；恢复后需要根据所恢复的数据和本地视频文件重新核对。

**数据库无法打开**  
左侧菜单会显示“数据库无法打开：原因”和“数据备份（恢复）”入口。该模式不能创建新备份；选择已有有效备份并确认后重启应用。无法打开的数据库会在恢复前自动备份。

### 信息不足时如何继续排查

若以上路径仍不能解释问题，记录以下非敏感信息后继续定位：应用版本、所在页面、选择的模型与服务商、执行步骤、预期结果、实际状态、完整错误文字和是否可重复。截图先遮挡密钥、令牌、账号、私人文本和素材。不要删除数据库、备份目录或生成文件来“试试看”；先备份并说明操作影响。

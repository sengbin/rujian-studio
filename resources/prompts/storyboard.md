## 镜头要求

- {{shotRules}}
- 每个镜头只表现一个连续的画面和一个主要动作；场景、时间或视角发生变化时另起镜头，并用 sceneLabel 标注所属场次。镜头的动作量要和时长匹配，2 到 5 秒的镜头只放一个简单动作。
- 镜头语言分别填在 shotSize（景别）、cameraAngle（机位与视角）、cameraMovement（摄影机运动）里，用具体的口语写，例如“大远景”“中景”“特写”“低角度仰拍”“平视”“24mm 广角”“固定镜头，摄影机静止”“推近”“拉远”“环绕”“手持跟拍”；三个字段都要填写。生成视频时程序会把它们写在提示词的最前面，所以 prompt 里不要重复镜头语言。
- prompt 是镜头的画面描述，直接用于视频生成模型，第一句先概括主体与主要动作（同时用作镜头列表的标题），再按进阶公式“主体（描述）+ 场景（描述）+ 运动（描述）+ 审美控制”写成连贯的短句：
  - 主体（描述）：核心对象的外观细节，用形容词或短句；人物写年龄、服饰、发型和神态，物体写材质、形状和颜色；
  - 场景（描述）：主体所处环境的细节，包括背景和前景；
  - 运动（描述）：运动的幅度、速度和效果，如“缓缓走近”“剧烈摇曳”“快速奔跑”，写清动作的先后顺序；实体清单里角色带有“表演与动作”的，它按情绪或情境分条；该角色出镜时，先判断当前镜头里它的情绪或情境，选用对应的一条（没有完全对应时取最接近的），把其中的表情、微表情、眼神和肢体动作写进 prompt，必须是画面里能看到的具体细节（如嘴角、眉眼、眼神方向、手部动作、重心变化），不能只写“表情痛苦”“动作紧张”这类笼统的词，也不要照抄原文或整段搬入；与剧情和台词相符，不要为此增加剧本没有的情节；没有填写的角色按剧情自然处理；
  - 审美控制：光源与光线环境（柔光、硬光、侧光、逆光、高对比度）、时间段、构图（中心构图、左侧重或右侧重构图）、色调（暖色调、冷色调、低饱和度）；景别、拍摄角度、镜头类型和运镜在 shotSize、cameraAngle、cameraMovement 里，程序会写在提示词最前面，所以 prompt 里不要重复；
  - 风格化：整体画面风格由程序统一写在提示词开头，不需要在每个镜头里重复风格关键词。
  只描述画面中能看到的内容，用正向表达，不写“不要”“避免”之类的否定句，不写镜头编号、台词和旁白。
- 以上一镜头尾帧作为首帧的镜头（连贯要求里指明的，或 firstFrameMode 为 prev_tail），主体、场景和风格已由首帧图片确定，prompt 改用图生视频公式“运动 + 运镜”的思路：重点写运动描述（幅度、速度和效果），主体和场景只用一句话点明、延续首帧，不再重新描绘外观；运镜仍填在 cameraMovement。
- transition 写与下一镜头的转场，如“叠化”；普通硬切填“切”。
- 同一实体在各镜头中的外观、服装、位置和光线保持一致，需要保持的要求写进 continuityNote。
- 镜头覆盖整集的主要剧情，顺序与剧本一致，不得增加剧本没有的情节。

## 站位与调度

- 每个镜头用 staging 写出出场的角色、道具、特效在画面里的站位，场景不需要站位；位置、朝向都以观众看到的画面为准，画面左侧就是观众的左边，不是角色自己的左边。
- 横向位置 startX、endX 取：画面左外、画面左侧、画面中央、画面右侧、画面右外；纵深位置 startDepth、endDepth 取：前景（靠近镜头）、中景、背景（远离镜头）。起点（startX、startDepth）是镜头开始时的位置，终点（endX、endDepth）是镜头结束时的位置；整个镜头里不移动就不填终点。从画面外进入，起点取画面左外或画面右外；走出画面，终点取画面左外或画面右外。
- 朝向 facing 取：面向镜头、背对镜头、面朝画面左侧、面朝画面右侧；action 写姿态或动作，如“坐在桌边”“端起茶杯”“向右转身”。
- 每个出场的角色都要有一条 staging；道具和特效只写需要明确摆放位置的（如桌子在画面中央背景）。
- 站位要符合剧情和空间常识：同一场次里角色与道具的相对位置前后镜头保持一致，面对面说话的两个角色朝向相反且位置左右分开，人物移动的方向与剧情和 cameraMovement 协调；以上一镜头尾帧作首帧的镜头，起点取上一镜头的终点。
- 站位只写在 staging 里，prompt 里不要重复写站位；prompt 的动作描述必须与 staging 一致。

## 声音

- 台词、旁白、音效和背景音乐只写在 sounds 里，不要写进 prompt；程序会把它们编译进最终的提示词。
- 声音按声音公式填写：提示词 = 主体 + 场景 + 运动 + 声音描述（人声、音效、背景音乐）。
  - 人声（dialogue、narration）= 角色台词 + 情绪 + 语气 + 音量 + 语速 + 音色 + 口音：台词填在 text，其余都填在 delivery，每条人声都必须填写 delivery 且写全，不能留空或只写“正常”。情绪如尴尬、愤怒、忐忑、得意；语气与音量如悄悄话、低声、正常说话、提高音量、大声喊叫；语速如慢、适中、快、急促；再加音色与口音。要与剧本里“角色名（语气）：台词”的标注、角色的表演设定和当下的剧情一致，例如“压低声音的悄悄话、语速偏慢、带着紧张”“大声呼喊、语速很快、急切”“尴尬地干笑、声音越说越小”“轻松的语气、适中的语速、清晰的嗓音”；
  - 人声的时间要和镜头对得上：中文台词按每秒约 4 个字估算（语速快时约 5 个字，慢时约 3 个字），每条人声都要填 startOffsetSeconds 和 durationSeconds；同一镜头里的人声按先后顺序排列、互不重叠，上一条说完再开始下一条，最后一条说完的时间不得超过镜头时长；台词多、镜头放不下时，先精简台词，或把镜头时长拉长（不超过上限），或拆成多个镜头，不要让台词被镜头截断；
  - 音效（sfx）= 发声材质 + 动作 + 环境音：text 写清发声物体的材质、发出声音的动作和环境音，如“小玻璃球落在木地板上发出‘啪嗒’一声，室内很安静”；
  - 背景音乐（music）= 背景音乐/配乐 + 风格：text 写配乐的风格和氛围，如“悬疑风格的背景音乐”。
  声音要与镜头里的画面和动作对应，按镜头内出现的先后顺序排列。

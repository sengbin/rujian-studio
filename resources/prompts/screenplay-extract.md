## 实体

抽取剧本中反复出现、需要保持一致外观或设定的实体，分四类：

- character 角色：有名字或固定称呼的人物、动物、怪物。
- scene 场景：故事发生的地点。
- prop 道具：对情节有作用、需要保持外观一致的物件。
- effect 特效：魔法、能量、天气异象等需要专门表现的视觉效果。

要求：

- name 使用剧本中最常见的稳定称呼，同类型内不重复；其他称呼放入 aliases。
- description 用一两句话概括设定。
- attributes 只填写该类型适用的字段，剧本没有给出的信息不要编造，留空即可。
- 角色的 performance（表演与动作）按情绪或情境分条书写，每条格式为“情境：表情与微表情；眼神；肢体动作”，先写 3 到 5 个该角色最常出现的情境（如平静、紧张、开心、愤怒、说谎或心虚，按角色实际取舍），总共不超过 800 字。依据角色的性格、身份和剧本中的情绪变化合理推演，写成画面里能看到的具体细节（嘴角、眉眼、眼神方向、呼吸、手部和重心等），可以有微表情和习惯性小动作；动物、怪物等非人类角色同样用拟人化的面部与肢体表达来写。不得复述剧情事件，不得与剧本设定冲突，不要为此添加剧本没有的情节；不要写“表情自然”“动作流畅”这类没有信息量的话。
- 只抽取剧本中确实出现的实体；一次性出现、无需保持一致的路人和背景物件不要抽取。
